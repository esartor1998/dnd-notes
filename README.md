### Getting the Notes Running on Your Computers
1. Ensure that git works on your system by opening a terminal and typing git status; it should complain that youre not in a git repository
2. While in the directory that you want the notes files to be kept in, clone this repo. It should ask for your key here, if you're not using key authenticaion by default, pushing and pulling will misbehave later.
3. Download https://obsidian.md/
4. Boot it, and select "Open folder as vault", selecting the dnd-notes folder you just cloned
5. Go into your Obsidian settings, enable community plugins with Community Plugins > Exit Restricted Mode (or whatever the button says)
6. Then download the Git plugin, by selecting Community Plugins > Browse (button), searching "Git" and downloading the plugin by user Vinzent.
7. Once downloaded, ensure that the plugin is also enabled, by checking that it is set in the on position under Community Plugins > Installed Plugins.
8. You should now be able to make changes to the content under the content folder, then push your changes as normal. Regular git stuff. If there are authentication issues, your system git may be configured oddly, and message me and we can work on it. Try to test out making and pushing some trivial changes to the index page, under [[dnd-notes/content/index|index]]: if you can successfully push, then everything is gucci.
